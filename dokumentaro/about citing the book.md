# About citing the book (如何引用本书)

您可以以如下 BibTeX 条目在 LaTeX 文档引用本书:
```bibtex
@unpublished{Determinantulo:EaD,
    author  = {{Determinantulo}},
    date    = {2025-06-28},
    note    = {This is an unpublished open-source textbook about determinants.},
    title   = {行列式入门},
    url     = {https://github.com/septsea/det},
    urldate = {2025-07-21},
    version = {版本 2π}
}
```
其中, `urldate` 是引用日期: 比如, 若您在 2025 年 7 月 21 日引用本书, 则您写 `urldate = {2025-07-21}` (注意, 日期的格式是 yyyy-mm-dd, 年-月-日). 则您可以看到 (我以 GB/T 7714-2015 标准为例):
> Determinantulo. 行列式入门[Z/OL]. 版本 2π. (2025‑06‑28) [2025‑07‑21]. https://github.com/septsea/det.

您可以读 [`how-to-cite-this-book.tex`](../diversajxoj/how-to-cite-this-book.tex) 以了解更多.
